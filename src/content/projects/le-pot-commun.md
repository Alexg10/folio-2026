## Context

Le Pot Commun is an online money pot platform used to collect money for gifts, events and shared expenses. Following a rebranding, the brand wanted a more dynamic, modern image, without rebuilding its Java back end. I joined the product team to lead the front-end side of this redesign.

## What I did

- Defined the new front-end stack: Next.js 15, Strapi 5, Tailwind CSS, Shadcn UI, next-intl, React Hook Form and Zod
- Built the redesign in 5 months, first on my own with the designer, then alongside other developers
- Plugged the new front end into the existing Java back-end APIs
- Set up Storybook to document and harmonise the UI components, and the CI/CD pipelines on GitHub
- Brought the new brand identity to life with GSAP animations
- Kept shipping new features after launch, driven by user feedback

## Outcome

A modern, more dynamic front end delivered in 5 months on top of the existing back end, with very positive feedback from the client.
