## Context

Le Pot Commun is an online money pot platform used to collect money for gifts, events and shared expenses. The existing front end needed a full redesign: the brand wanted a more dynamic, modern image, without rebuilding its Java back end.

## What I did

- Proposed and set up the new front-end stack: Next.js, TypeScript and Tailwind CSS
- Rebuilt the whole front end from the existing site, on top of the Java back-end APIs
- Connected Strapi as a headless CMS so the team could manage content on its own
- Handled internationalisation with i18n and global state with Zustand
- Brought the new brand identity to life with GSAP animations

## Outcome

A modern, more dynamic front end delivered on top of the existing back end, with very positive feedback from the client.
